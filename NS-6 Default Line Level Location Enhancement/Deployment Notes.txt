hardcoded in the script is now held on the Location record.

Steps to deploy:

1.  Other Record Fields

    Name:   Default Line Inventory Location
    ID:     _cmc_default_line_inv_loc
    Type:   List/Record - Location
    Rec:    Location

2.  Update Script

    Name:   [MS] UE Default Line Inventory Location
    ID:     customscript_ms_ue_dflt_line_inv_loc
    Type:   User Event
